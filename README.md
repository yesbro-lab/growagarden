# My Custom Homepage Template

This is a personal homepage template project originally built using the CodeHS HTML/CSS editor and successfully migrated over to GitHub Pages for live web hosting.

## Project Features
- Built completely from scratch using valid semantic HTML5 structure.
- Clean layout formatting designed with custom CSS styling rules.
- Fully compatible with modern mobile and desktop web browsers.

## How to View the Live Demo
You can open and interact with the live deployed version of this webpage template by visiting the hosted site here:
👉 [Click Here to Open the Live Webpage](https://github.io)

## Technology Stack
- **HTML5**: Used for defining the typography elements, links, and content containers.
- **CSS3**: Used for managing global layout structures, text colors, alignment, and formatting rules.
